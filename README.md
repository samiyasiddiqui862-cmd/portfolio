# Samiya Siddiqui — Developer Portfolio

A modern, highly responsive, production-ready portfolio website for **Samiya Siddiqui**, B.Sc. Data Science Student and Full Stack Web Developer.

## 🚀 Features
- **Zero Build Step**: Built with semantic HTML5, modern CSS3 (Custom Properties, Flexbox, CSS Grid), and modern Vanilla JavaScript (ES6+).
- **Dual Theme Support**: Dark mode (default) and Light mode with persistent state saved in `localStorage` and system theme sync.
- **Dynamic Micro-Interactions**:
  - Interactive constellation canvas background responding to cursor movement.
  - Animated typewriter headline in hero section.
  - Time-aware dynamic greeting.
  - Reveal-on-scroll animations via `IntersectionObserver`.
- **Project Detail Modals**: Interactive modal previews for HRMS Company Management System, EventHub 360 Fleet Module, and Regional Water Usage Analysis.
- **Accessible & Responsive**: WCAG AA contrast compliance, keyboard navigable, screen-reader friendly, and mobile-first layouts.
- **1-Click Actions**:
  - Direct clipboard copy for email and phone numbers.
  - Clean resume printable view (`@media print` stylesheet) and PDF export.
  - Form validation with simulated feedback.

## 💻 Local Development
Simply open `index.html` in any modern web browser, or run the zero-dependency local server:
```bash
node server.js
```
Then visit `http://localhost:8080`.

## 🌐 Deployment
Ready for 1-click deployment on **Vercel**, **Firebase Hosting**, **Netlify**, or **GitHub Pages**.
